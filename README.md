# TrailMate - Local Tourism Guide 🧭

A responsive local tourism web application built with React, Vite, and React Router.

## 🌐 Live Website
**[https://harshad062.github.io/exp-8-1/](https://harshad062.github.io/exp-8-1/)**

---

## 🚀 Features
- **Home**: Curated destinations, highlights, statistics, and quick navigation.
- **Trip Planner**: Interactive itinerary planner for exploring destinations.
- **Traveler Registration**: Complete form with validation for name, email, password strength, age (18-30), mobile number, gender, and state.
- **Traveler Login**: Member login portal with perks overview.
- **About & Contact**: Mission statement and direct inquiry options.

## 🛠️ Tech Stack
- **React 18**
- **Vite 5**
- **React Router DOM 6** (HashRouter for seamless GitHub Pages routing)

## 💻 Local Development

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build locally
npm run preview
```
